Data Preprocessing & Feature Engineering
The Date and GLD columns were dropped from features. No scaling or normalisation was applied — Random Forest is scale-invariant. No lag features or rolling statistics were engineered; the four raw market indicators (SPX, USO, SLV, EUR/USD) were used directly as they showed the most direct correlation with gold.
X = gold_data.drop(['Date', 'GLD'], axis=1)  # features: SPX, USO, SLV, EUR/USD
Y = gold_data['GLD']                          # target
.drop(['Date','GLD'], axis=1)No scaling needed

Train / Test Split
80/20 split using random_state=2 for reproducibility. This gives 1,832 training rows and 458 test rows. No cross-validation or time-series-aware splitting (e.g. TimeSeriesSplit) was used — this is a point-in-time prediction task rather than forecasting.
X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y, test_size=0.2, random_state=2
)

Model Training — Random Forest Regressor
An ensemble of 100 decision trees. Each tree is trained on a random bootstrap sample of the training data and splits on a random feature subset at each node. Final prediction is the mean of all tree outputs. No random_state was set on the model itself; set one for full reproducibility.
regressor = RandomForestRegressor(n_estimators=100)
# Full default hyperparameters:
# max_depth=None, min_samples_split=2, min_samples_leaf=1,
# max_features='auto' (sqrt of n_features for regression → 2),
# bootstrap=True, n_jobs=None, random_state=None

regressor.fit(X_train, Y_train)

Reproducibility seed

The train/test split uses random_state=2. The RandomForestRegressor did not have a random_state set — minor prediction variance may occur between runs. For full reproducibility, set:

regressor = RandomForestRegressor(n_estimators=100, random_state=2)

Feature Importance

The Random Forest Regressor internally computes feature importances based on mean impurity decrease across all trees. Extract them with:

importances = regressor.feature_importances_
feature_names = X.columns
for name, imp in zip(feature_names, importances):
    print(f"{name}: {imp:.4f}")

Based on the strong correlation found in analysis, SLV is expected to be the most important feature, followed by EUR/USD. SHAP analysis was not performed in this version but is recommended for deeper interpretability.

Limitations & Assumptions
This is a correlation-based prediction model, not a forecasting model. It does not predict future prices — only the price given the current values of the other market indicators.
  • No time-series awareness: The split is random, not temporal. Future versions should use TimeSeriesSplit to avoid data leakage.
  • No cross-validation: Hyperparameters were not tuned. Grid search or random search is recommended.
  • Market shocks: The model may perform poorly during sudden geopolitical or macroeconomic events not represented in the training data.
  • Stationarity assumption: The model assumes the relationship between features and gold price is stable over time.
  • No baseline comparison: A simple mean predictor or linear regression baseline was not computed for comparison.
  • Data freshness: The dataset ends at May 2018. Retrain with updated data for current predictions.
